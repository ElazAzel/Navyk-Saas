# NAVYK — платформа карьерного развития студентов

NAVYK — это SaaS для университетов, студентов, менторов и работодателей. Платформа помогает управлять карьерными траекториями, проводить консультации и публиковать вакансии.

## Основные возможности
- Профиль студента с аналитикой прогресса
- Запись на курсы и мероприятия университета
- Поиск и бронирование консультаций с менторами
- Публикация вакансий работодателями

## Локальный запуск
```bash
npm install
npm run dev
```

## Развертывание на Vercel
Приложение оптимизировано для [Vercel](https://vercel.com).
Для деплоя установите CLI и выполните:
```bash
npm i -g vercel
vercel deploy
```
