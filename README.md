# NAVYK — платформа карьерного развития студентов

NAVYK — это SaaS для университетов, студентов, менторов и работодателей. Платформа помогает управлять карьерными траекториями, проводить консультации и публиковать вакансии.

## Основные возможности
- Профиль студента с аналитикой прогресса
- Запись на курсы и мероприятия университета
- Поиск и бронирование консультаций с менторами
- Публикация вакансий работодателями

## Локальный запуск
```bash
npm install
npm run dev
```

## Развертывание на Vercel
Приложение оптимизировано для [Vercel](https://vercel.com).
Для деплоя установите CLI и выполните:
```bash
npm i -g vercel
vercel deploy
```

Сбор статистики посещений и производительности осуществляется через
[@vercel/analytics](https://vercel.com/docs/analytics) и
[@vercel/speed-insights](https://vercel.com/docs/speed-insights),
которые подключены в корневом макете приложения.

## AI возможности
В прототип встроена интеграция с OpenAI для генерации контента:

- **AI-помощник ментора** — формирует персонализированный план обучения по названию навыка.
- **Генератор описаний вакансий** — создает текст вакансии на основе ключевых слов.
- **AI-чат для студентов** — отвечает на вопросы о карьере и развитии навыков.

Для работы функций задайте переменную окружения:

```bash
export OPENAI_API_KEY=ваш_ключ
```
