# Руководство по деплою в продакшн

Этот проект построен на Next.js с использованием TypeScript и Tailwind CSS. Ниже приведены шаги, которые помогут подготовить и запустить приложение в продакшн-среде.

## 1. Предварительные требования

- Node.js LTS (используйте версию, указанную в `package.json` в разделе `engines`, либо последнюю LTS)
- npm 8+ или pnpm/yarn (на ваш выбор)
- Доступ к выбранной продакшн-платформе (например, Vercel, AWS, Render, любой VPS)
- Переменные окружения, необходимые для работы API и интеграций (см. `.env.example`, если он доступен)

## 2. Проверка и подготовка к релизу

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Запустите линтеры (и тесты, когда они появятся в проекте):
   ```bash
   npm run lint
   # npm test
   ```
   > Примечание: команда `npm test` будет добавлена в руководство, как только в проекте появятся автоматические тесты.
3. Соберите продакшн-бандл локально, чтобы убедиться в отсутствии ошибок сборки:
   ```bash
   npm run build
   ```
4. Запустите продакшн-сервер локально для финальной проверки:
   ```bash
   npm run start
   ```

## 3. Деплой на Vercel (рекомендуемый способ для Next.js)

1. Установите [Vercel CLI](https://vercel.com/docs/cli) при необходимости:
   ```bash
   npm i -g vercel
   ```
2. Выполните логин в Vercel:
   ```bash
   vercel login
   ```
3. Настройте проект (первая публикация):
   ```bash
   vercel
   ```
   Следуйте инструкциям в терминале, выбрав существующую организацию/команду и задав переменные окружения в настройках проекта на сайте Vercel.
4. Для повторных релизов используйте команду:
   ```bash
   vercel --prod
   ```
   Она отправит свежий билд в продакшн и сделает его доступным по продакшн-домену.

## 4. Альтернативный деплой через Docker

1. Соберите Docker-образ:
   ```bash
   docker build -t navyk-saas:latest .
   ```
2. Запустите контейнер:
   ```bash
   docker run -d -p 3000:3000 --env-file .env.production navyk-saas:latest
   ```
3. Настройте обратный прокси (например, Nginx или Caddy) для выдачи приложения по HTTPS.

## 5. Чек-лист перед выкладкой

- [ ] Все обязательные переменные окружения заданы
- [ ] База данных и внешние сервисы доступны из продакшн-среды
- [ ] Категория данных пользователей соответствует требованиям GDPR/152-ФЗ (если применимо)
- [ ] Настроен мониторинг (например, Vercel Analytics, Sentry, Logflare)
- [ ] Создан план отката (rollback) на предыдущую стабильную версию

Следуя этим шагам, вы сможете безопасно подготовить проект к релизу и выполнить деплой без прямого доступа ассистента к продакшн-среде.
